# 项目演示

## 先看界面，不装数据库

在项目根目录执行：

```bash
python -m http.server 8080 --directory demo
```

打开 http://localhost:8080 。这是离线交互演示，使用仓库里的虚构示例内容，展示提问、查出处和继续追问的流程。没有调用大模型、联网搜索或真实数据库；显示的流程不是实际后端运行日志。

## 再跑真实流程

1. 按README配置数据库、模型和API。
2. 打开导入页 http://localhost:8000/import ，上传你有权使用的PDF或Markdown。
3. 等待任务状态显示完成。
4. 打开问答页 http://localhost:8001/chat.html ，提问并检查答案与原始文档是否一致。
5. 配置了MCP搜索时才具备联网补充资料的条件；具体服务能否使用取决于你的账号。

仓库不包含真实设备手册、学习笔记、聊天记录或本机模型。完整导入/问答需自行配置服务；本次发布没有冒充完成真实API端到端验证。
